# 题材库与板块强度参考页改版计划

## 目标

以 `金十AI题材库/themeku.html + themeku_theme.css` 的曜石红玉暗黑主题作为全站视觉基线；题材库采用左侧题材列表、中间详情、右侧实时播报的三栏格局；板块强度采用 `kpl/index.html` 的左侧排行、右侧板块详情与成分股格局。保留现有数据模型、懒加载、标签互跳和五个主导航。

## 任务 1：全局暗黑 CSS

1. 将参考页暗黑变量抽取到 `apps/web/assets/app.css`，默认 `html[data-theme=dark]`。
2. 统一顶栏、面板、输入框、表格、徽章、滚动条和响应式断点。
3. 不复制会员、支付等与工作台无关样式。

## 任务 2：题材库三栏布局

1. 左栏：标题、题材总数、搜索、排序提示、全量题材列表。
2. 中栏：当前题材摘要、细分概念、成分股表；首次进入默认选择第一项。
3. 右栏：复用当日事件流作为实时播报；移动端折叠为单栏。
4. 保留题材搜索、点击选择、成分股懒加载和板块/题材互跳。

## 任务 3：板块强度 KPL 布局

1. 左栏保持 340px：日期、搜索、强度排行、涨跌和涨停统计。
2. 右栏：板块标题与指标、子板块标签区、筛选栏、成分股表。
3. 首次进入默认选择排名第一板块；点击左侧实时切换详情。
4. 当前日视图没有分时序列时展示明确空态，不伪造曲线。

## 任务 4：验证与部署

1. 增加渲染结构测试，确保必要布局类名和默认暗黑主题存在。
2. 运行全量测试、构建与本机部署。
3. 通过 localhost 浏览器分别验收题材库、板块强度、响应式布局和 console。
