# V0.1a 数据管线实现计划

> **面向 AI 代理的工作者：** 按 `docs/DEVELOPMENT_PROCESS.md`（superpowers 流程）逐任务实现本计划，步骤使用复选框（`- [ ]`）跟踪进度。先计划后代码；核心逻辑 TDD。

**目标：** 建立统一采集器 `services/collector`，产出符合 `docs/DATA_MODEL.md` 的规范化数据（主数据 + 日K + 板块因子 + 归档 + Web 视图层），单日全链路可跑通。

**架构：** 主数据（开盘啦 API）+ 日K（TDX vipdoc 前复权）+ 板块因子（东财资金流/选股宝领涨原因）→ 纯函数清洗（normalize）→ 每日归档生成 facts → 派生 Web 视图层（裁剪+gzip）→ `data/web/` 供 nginx 直出。

**技术栈：** Python 3.10（无第三方依赖的核心库；requests/paramiko 仅 deploy）、pytest、通达信 vipdoc `.day` 二进制解析、JSON/gzip。

**依赖：** 数据模型见 `docs/DATA_MODEL.md`；策略口径见 `docs/STRATEGY_MODEL.md`；接口经验见 `docs/DATA_MODEL.md` §9。

```python
# services/collector/normalize.py
import re

def clean_ps_artifact(text):
    """PowerShell @{k=v; ...} 残留 → dict。规则见 DATA_MODEL §7-6（sources 保留原文）。"""
    if not text.startswith("@{"):
        return {"_raw": text}
    body = text[2:-1]
    out = {}
    for part in re.split(r";\s*(?=\w+=)", body):
        if "=" in part:
            k, v = part.split("=", 1)
            out[k.strip()] = v.strip()
    return out

def stock_id(code):
    code = code.strip()
    if code.startswith(("60", "68")):
        return "SH" + code
    if code.startswith(("00", "30")):
        return "SZ" + code
    return "BJ" + code  # 8/4/92 → 北交所

def sector_type(sector_id):
    return "industry" if sector_id.startswith(("8019", "803", "880")) else "concept"
```
