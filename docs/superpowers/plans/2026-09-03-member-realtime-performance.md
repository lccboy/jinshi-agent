# 会员实时环境性能优化实施计划

## 目标

在不改变历史归档、策略公式和会员私有边界的前提下，降低 8790 实时 TAB 的首屏及轮询延迟。

## 实施步骤

1. 为公共实时接口增加轻量模式；非竞价 TAB 不生成、不传输竞价雷达候选明细。
2. 会员同步只拉取轻量实时快照；8790 页面请求优先读取已原子落盘的本地快照。
3. 8790 JSON 响应增加 gzip、ETag 和 304，减少重复序列化与网络传输。
4. 会员策略计算增加有界节流；输入修订变化仍会计算，但不允许昂贵计算连续挤占服务线程。
5. 前端非竞价 TAB 统一请求轻量实时接口，竞价雷达维持独立按需加载。
6. 运行聚焦测试、全量回归、真实接口计时和浏览器验收，再发布三个环境。

## 安全边界

- 不修改⑧金量买入公式及22个策略模型口径。
- 不覆盖历史日期归档；实时缓存仍可丢弃并重建。
- 会员 K 线、配置、自选及私有策略结果不上传公共服务器。
- 轻量模式仅删除当前 TAB 不消费的冗余字段，不伪造、不延后数据日期。
