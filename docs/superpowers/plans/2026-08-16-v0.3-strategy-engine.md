# V0.3 策略引擎 + 后台数据完善实现计划

> **面向 AI 代理的工作者：** 按 `docs/DEVELOPMENT_PROCESS.md` 逐任务实现，复选框跟踪进度；核心逻辑 TDD。
> 依赖：V0.1a（数据管线）+ V0.1b（前端视图框架，策略/预警视图等待本计划的数据）。

**目标：** 让 `策略模型` 与 `历史选股（预警池）` 视图有真实数据——17 个模型跑真实日K，产出 `facts/<date>/strategy.json`、`pool.json`、`events.json`，叠加四维确认；打通 主数据→日K→策略→预警 的后台闭环。

**架构：** `indicators.py`（指标纯函数）→ `strategy_models.py`（17 模型条件/评分）→ `strategy_engine.py`（编排：读 kline + config/strategy.json + 叠加层 → 写 facts + 事件 + 预警池）；买点评分按 STRATEGY_MODEL §4，⑧金量买入复用 `models/golden_vol.py`（**口径不可改**）。

**技术栈：** Python 3.10 纯 stdlib、pytest、真实 TDX 前复权日K（data/kline/）。
