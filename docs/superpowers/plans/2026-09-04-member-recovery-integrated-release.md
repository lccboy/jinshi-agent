# 1.0.39 会员安装与守护闭环

## 边界
- 数据：仅安装状态、守护状态和有界日志；保留原 data_root、授权和所有归档。策略、行情、数据格式不变。
- 资源：8790绑定先于后台线程；安装与守护共用互斥锁，升级期间不得拉起旧进程；守护每60秒、15分钟最多3次。
- 依赖：Windows自带PowerShell与计划任务，无新采集依赖。
- 接口：无业务API变更。安装成功需版本健康检查和持久守护配置均通过；NoLaunch明确标记未验收。
- 失败：任务注册失败尝试当前用户启动项；均失败返回非零，保留已安装程序与数据，输出重试主安装器说明。启动日志不含凭据。
- 发布：8790完整包；8080和公共服务器只更新版本下载链接、指南、ZIP及哈希，不修改公共采集和会员私有数据。

## 步骤
1. TDD：打包包含守护、主安装器调用、升级/卸载锁、先绑定后采集、权限失败不可成功、原数据路径与同版回滚保留。
2. 主安装器整合守护、互斥与健康门禁；守护配置任务或用户启动项，禁用/卸载移除入口并停止循环。
3. 修改后台绑定顺序；版本同步为1.0.39，更新使用说明。
4. 聚焦及全量测试；隔离PowerShell运行验证权限回退、升级/回滚/卸载与数据保留。真实包验证内容、启动、重复启动、授权哈希及8790健康。
5. 定向发布下载文件，逐文件远程哈希核对；验收记录说明无法在本机执行的注销/重登测试，不宣称未验证场景通过。

## 资源预算与回退
守护一次仅查询端口和指定进程；健康时不写日志，异常日志最多2MB，运行时状态KB级；无按天新增行情。禁用守护退出循环，回滚按install_state选旧版本。禁止无限快速重启或杀死非本安装目录进程。
