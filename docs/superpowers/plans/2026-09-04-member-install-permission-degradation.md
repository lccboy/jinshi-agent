# 1.0.40 安装权限降级

复现1.0.39在计划任务和启动目录均拒绝写入时抛错。修正为主程序与永久守护分别报告：永久守护不可配置时启用session_only，明确告警但不阻止已健康的主程序安装。NoLaunch只配置不启动。

边界：不改采集、策略、授权或归档；复用一分钟守护、三次/15分钟限制；不提升权限，不修改ACL，不绕过Windows策略。只更新安装脚本、版本下载包及指南。

步骤：先失败测试双权限拒绝；实现有限降级；隔离与全量测试；构建1.0.40并用实际受限身份安装；健康和授权校验通过后定向发布并核对哈希。仍明确未验证注销后恢复，不将session_only描述为永久守护。
