# 板块页自动实时、通达信联动与历史涨停原因计划

## 目标

交易时段进入板块页即展示当天开盘啦实时数据，移除手动实时按钮；盘后读取当天归档。个股整行可联动通达信，实时涨停原因沿用最近历史记录并支持自适应弹窗查看多源详情。

## 步骤

1. 为交易时段判断和实时原因回填增加测试。
2. 扩展开盘啦实时板块接口：为成分股批量附加最近历史涨停原因、原因日期和多源信息。
3. 前端进入板块页时按交易日/时间自动启动实时轮询，日期区显示“当天 · 实时”；移除手动切换按钮。
4. 个股表格整行绑定通达信链接；涨停原因渲染为可点击按钮，使用现有自适应弹窗展示来源和历史日期。
5. 全量测试、真实 API 验证、构建部署和提交。

## 日期导航补充

- 板块日期栏左右箭头按交易日切换；实时状态向左进入最近归档，最新归档向右回到当天实时。
- 右上角全局日期选择增加“当天 · 实时”，选择后恢复开盘啦实时轮询。
- “当天 · 实时”按当前页面分流：题材库启动自己的腾讯实时涨停/题材直播，板块页启动开盘啦板块实时。
