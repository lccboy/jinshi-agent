# V0.1b 静态工作台渲染实现计划

> **面向 AI 代理的工作者：** 按 `docs/DEVELOPMENT_PROCESS.md` 逐任务实现，复选框跟踪进度。
> 依赖：V0.1a 已完成（`data/web/day_<date>.json` 视图层就绪，tag v0.1.0）。

**目标：** 静态 SPA 五个视图渲染 `data/web/` 真实数据（涨停信号 / 题材库 / 板块强度 / 策略模型 / 历史选股），支持日期切换（immutable 缓存）与通达信联动。

**架构：** 纯静态前端（无构建、无框架，vanilla JS）——`index.html` + `app.js` + `app.css`；数据只读 `data/web/`（index.json + day_<date>.json + 懒加载 .detail.json）；nginx gzip_static + immutable 缓存（DATA_MODEL §13）。

**技术栈：** HTML/CSS/vanilla JS（零依赖）、`node --check` 语法校验、Python http.server 本地验证。
