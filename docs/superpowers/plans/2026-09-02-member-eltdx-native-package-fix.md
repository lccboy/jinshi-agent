# 会员竞价雷达 eltdx 原生扩展打包修复计划

## 根因与验收

- `1.0.28` 仅通过 `--hidden-import eltdx` 收集 Python 入口，遗漏 `eltdx/_native.pyd`，冻结程序创建 `TdxClient` 时失败。
- 新包必须包含原生扩展，并由冻结程序执行本地运行时自检；8790“测试连接”不能再出现 Rust extension unavailable。

## 六个边界

- 数据：不修改竞价事实、归档和策略结果；只修正会员程序依赖打包。
- 资源：不新增常驻进程、端口或轮询；连接测试仍使用既有 3 秒预算。
- 依赖：继续固定 `eltdx==3.0.8`，只改变 PyInstaller 收集方式。
- 接口：沿用 `/api/auction/test-connection`，不新增公共接口。
- 失败：原生扩展或主站不可用时继续局部失败关闭，不影响腾讯公共雷达。
- 发布：开发构建与冻结 smoke 通过后部署 8790；服务器只发布静态页面和会员下载包，不安装 eltdx、不改变公共采集。

## TDD 与发布步骤

1. 增加构建脚本必须收集 `eltdx` 全包、冻结 smoke 必须执行原生运行时检查的失败测试。
2. 最小修改构建与 smoke 脚本，生成 `1.0.29`。
3. 检查包内 `_native.pyd`，运行冻结 smoke，再安装 8790 并在页面执行连接测试。
4. 跑完整测试，发布升级包，提交本任务文件并推送。

## 容量

- 仅增加一个原生扩展及 eltdx 运行文件，预计安装包增加数 MB；无每日、20 日或年度数据增量。
