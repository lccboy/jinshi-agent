# 会员历史选股当天池有界修复计划

## 根因

会员本地实时结果已经包含 `pool.alert` 与 `pool.candidate`，但 8790 的轻量兼容响应只下发模型命中、可买预警和事件；前端合并时也没有用会员池覆盖公共 `history_pools`。公共服务器当天池为空，因此当天页面显示空池。

## 实施

1. 增加纯函数测试测试，固定统一排序、竞价候选排除和 30/100 上限。
2. 8790 从现有本地实时文件投影轻量 `history_pools` 与汇总，不增加采集或策略计算。
3. 前端同日期时优先合并会员 `history_pools`，历史日期仍读取冻结归档。
4. 验证重点预警30只、候选最多100只及总数361，记录响应体积和耗时。
5. 全量测试、构建安装、真实页面验收并发布。

## 性能边界

- 不新增网络请求和定时器。
- 不返回完整2915条模型命中或361条候选；保持既有 Web 上限。
- 投影仅处理内存中的有界字典，不触发 K 线读取或模型重算。
