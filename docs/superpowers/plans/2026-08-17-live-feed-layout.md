# 实时直播股票列表排版优化计划

## 目标

保留模型命中按分钟归类，重构每个时间组下的股票行，使中文名、代码、涨幅、模型标签和评分在 300px 左右的右栏中层级清晰、对齐稳定、便于快速扫读。

## 任务 1：实际页面检查

1. 在部署页面打开今日实时，检查时间组、长股票名、多模型标签、正负涨幅和滚动状态。
2. 记录导致拥挤的 DOM/CSS 结构，不改变数据接口。

## 任务 2：紧凑列表布局（TDD）

1. 先增加布局标记测试，要求时间组摘要、股票主行、模型次行和评分区域结构分离。
2. 股票主行采用“中文名 + 代码 / 涨幅”结构，次行模型标签可换行，评分固定靠右。
3. 增强时间组标题、组间层次、悬停反馈、涨跌色和窄栏溢出处理。

## 任务 3：部署验收

1. 运行前端结构测试与全量测试。
2. 构建部署，用浏览器检查实际文字、尺寸、滚动和控制台错误。
