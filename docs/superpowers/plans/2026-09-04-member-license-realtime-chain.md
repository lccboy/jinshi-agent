# 会员授权与当天数据链统一修复

## 已证实
8790授权缓存checked_at停在9月3日12:12，9月4日超过24小时门禁；上午本地已有2915模型与30预警，授权过期后接口关闭。无会话cookie的validate返回local token required，取新首页cookie后同一码同设备云校验成功，后台立即恢复计算。

## 边界
- 数据：只增加runtime授权刷新诊断；不写回公共数据、不改交易日、不重写冻结历史。现有授权有效期/设备/24小时离线门禁不放宽。
- 资源：独立授权维护线程，6小时校验一次，失败至少5分钟再试，15秒网络超时；不阻塞行情同步或页面API。
- 依赖：标准库，无新增外部依赖；开启会员本地服务时修复既有授权维护，不向公共服务发布会员代码。
- 接口：POST遇到本地会话过期仅重新获取同源HttpOnly cookie并重试一次；不删除token/Origin校验。公开页面维持原行为。
- 失败：明确云端拒绝使相同缓存授权失效；网络失败保留原缓存但不延长checked_at。界面不再仅显示HTTP403。
- 发布：8790新包与三项真实接口核对；8080/服务器仅更新前端和ZIP。版本、缓存标识、包哈希一致。
