1. 数据：模型原始命中仍保留在私有 `strategy.json`；收敛只作用于正式池与Web物化；冻结历史先备份再版本化重算。
2. 资源：复用盘后策略进程，API只读单日 `pool.json`，不扫全量K线。
3. 依赖：服务器只下发公共规则/配置；会员K线与私有结果不上行。
4. 接口：`/api/pools?date=` 保持现有字段，已授权会员用私有 `alert/candidate/watchlist` 覆盖名池。
5. 失败：配置缺失时使用明确默认门槛；无公共主数据或无会员私有池时不发布空文件覆盖旧结果。
6. 发布：8080回放→公共服务器配置/兼容包→8790同步规则并用本地K线重算；服务器包不含会员模块。
