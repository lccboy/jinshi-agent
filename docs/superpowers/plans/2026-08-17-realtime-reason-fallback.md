# 实时涨停原因最近交易日回填计划

## 目标

腾讯实时检测出的涨停股若当天尚无涨停原因，则沿用该股最近一个交易日的归档涨停原因；当天已有原因时绝不覆盖。前端必须显示原因所属日期，避免把历史原因误认为当天口径。

## 任务 1：最近原因聚合（TDD）

1. 在实时接口测试中增加一只当天无原因、前一交易日有多源原因的涨停股，先确认失败。
2. 按 `facts/<date>/limitup.json` 日期倒序查找每只股票最近一条原因，只补缺失项。
3. 保留 `primary/sourceCount/sources`，增加 `reason_date` 与 `reason_is_history`；当天原因标记为非历史。

## 任务 2：卡片标识与详情（TDD）

1. 下方实时涨停卡片继续显示原因，同时在来源标签中注明“沿用 YYYY-MM-DD”。
2. 最近日原因的多源原文继续进入现有自适应弹窗。
3. 历史归档模式保持原样，不增加沿用标识。

## 任务 3：验证部署

1. 运行接口、布局和全量测试。
2. 重启 API、部署静态页面，在今日实时模式确认有原因卡片、日期标识和无控制台错误。
