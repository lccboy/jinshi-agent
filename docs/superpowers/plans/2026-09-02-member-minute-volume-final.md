# 会员分钟爆量最终实施计划（V1.0.30）

## 目标

在不改变公共数据、策略模型和既有归档的前提下，将分钟爆量改为会员本地可复现链路：当天只读公共自然分钟增量并与本地冻结基线计算；收盘后从通达信 LC1 生成独立按日归档，供下一交易日使用。

## 数据边界与口径

- 主归档：`members/<member_id>/archive/<date>/minute_volume.ndjson.gz`。
- 事件归档：`members/<member_id>/archive/<date>/minute_events.ndjson.gz`。
- 完整性清单：`members/<member_id>/archive/<date>/minute_manifest.json`。
- 昨日基线：`members/<member_id>/facts/<date>/minute_baseline.json`。
- 归档只写上述独立路径，不覆盖策略、竞价、历史选股或公共归档。
- 目标日只接受其之前最近一个完整 LC1 交易日；不能用更老缓存冒充昨日。
- 五档筛选：`>=0.5x`、`接近昨量(0.8x<=r<1.0x)`、`超昨峰(>=1.0x)`、`>=1.5x`、`>=2.0x`。

## 实施步骤

1. 先增加严格基线、独立归档、筛选档位与前端状态的失败测试。
2. 实现 LC1 指定日期归档、原子写入、SHA256 清单、完成归档不可覆盖和差异隔离。
3. 修复会员服务旧基线短路；实时接口返回数据日、基线日、质量、档位计数与明确空态。
4. 增加收盘归档单次执行与启动补偿能力，失败只影响分钟爆量。
5. 按原型优化筛选与状态区，保留轻量轮询及按需加载三日详情。
6. 回填可用历史日并核对归档/基线；执行聚焦测试、全量测试和真实 8790 浏览器验收。
7. 构建并发布 V1.0.30，安装会员本地包，提交限定文件并推送。

## 验收门禁

- 相同源数据重复归档幂等；不同内容不得覆盖完成归档。
- 实时数据日期与基线日期明确可见，盘前/缺源不伪装实时。
- 归档日可独立读取，删除/损坏某日不影响其他日及其他功能。
- 默认页面能看到接近昨量候选，五档切换口径准确。
- 公共包和同步清单不包含会员路径、原始 LC1、私有归档或连接信息。
