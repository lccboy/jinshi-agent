# 会员策略模型实时数据修复计划

## 根因

会员本地实时计算已经正常生成 `model_hits`，但策略模型 TAB 只读取公共 `/api/intraday/latest`；公共响应按边界不包含会员私有模型结果。实时信号和题材库已有本地 JSONP 合并，策略模型页遗漏了同一合并步骤。

## 实施

1. 增加前端回归测试，要求策略实时刷新同时读取公共快照、本地会员实时结果和定格策略文件。
2. 仅合并日期一致且 `available=true` 的会员本地结果，继续保持公共/私有边界。
3. 保留本地未授权、日期不一致和网络失败时的原有降级行为。
4. 构建会员版本并安装到 8790，验证接口与浏览器 DOM 的实时命中数量。
5. 执行测试、服务器发布、限定提交并推送。
