# 开盘啦板块强度全链路实时刷新计划

## 目标

板块实时模式统一使用开盘啦口径：主板块强度排行、资金流、子板块强度以及选中板块成分股同步刷新；腾讯仅保留在实时涨停检测模块，不参与板块强度页。

## 步骤

1. 为 `RealRankingInfo`、`SonPlate_Info`、`ZhiShuStockList_W8` 编写返回值解析测试，覆盖概念/行业字段和完整个股数值列。
2. 新增开盘啦板块实时采集模块，提供短时缓存、分页主板块排行、选中板块子板块及成分股采集。
3. 将 `/api/sectors/realtime` 改为开盘啦数据源，返回统一的 `sectors/sub_sectors/stocks` 结构和源时间，不再叠加腾讯快照。
4. 前端实时模式按固定节奏刷新排行、资金、子板块和个股；保持当前选择与历史矩阵联动。
5. 全量测试、真实 API 验证、构建部署和页面回归。

## 数据规则

- `strength` 原样采用开盘啦服务端字段，不在本地重算。
- 盘中快照只追加；实时接口结果只用于展示，不覆盖历史事实。
- API 异常时保留最后一帧并显示数据时间，不生成模拟数据。
