# 板块分时图、个股排序与筛选口径修复计划

## 目标

补齐开盘啦板块分时图并支持收起/展开；个股表所有业务列可排序；地位按“龙一…龙十二”中文序数排序；`>6%` 与涨停筛选互斥。

## 步骤

1. 采样 `GetVolTurIncremental` 与 `GetTrendIncremental`，为分时解析、中文地位序数、涨幅分类先写测试。
2. 扩展开盘啦实时接口，返回选中主板块的分时成交/资金走势与价格走势。
3. 前端使用 Canvas 绘制分时图，增加展开/收起按钮并记住本次页面状态。
4. 个股表头增加排序状态和点击事件；数值列按数字排序，地位列按中文序数排序，文本列稳定排序。
5. 修正筛选：涨停 `>=9.8%`，`>6%` 为 `6% <= 涨幅 < 9.8%`。
6. 全量测试、真实 API 验证、构建部署。
