# V0.3 盘中实时链路实现计划（quote_collector + limit_detect + intraday + 事件引擎）

> **面向 AI 代理的工作者：** 按 `docs/DEVELOPMENT_PROCESS.md` 逐任务实现，复选框跟踪进度；核心逻辑 TDD（先写失败测试→红灯→最少实现→绿灯）。
> 依赖：V0.1a 数据管线 + V0.3 盘后策略引擎（已完成）。本计划补齐 V0.3 的**盘中实时半边**。
> 依据规格：`docs/DATA_MODEL.md` §5（盘中快照）、§10（涨停检测规则）、§4.12/4.13（事件流+预警池）、`docs/STRATEGY_MODEL.md` §7（盘中实时命中机制）。

**目标：** 打通 腾讯行情(3s 全市场) → 涨停检测（腾讯+规则，与 KPL 交叉验证）→ intraday 快照（ndjson 只增）→ 事件驱动引擎（limitup/broken/signal_hit 盘中命中）→ 分层预警池实时维护，使"盘中实时预警"能力真正可用。

**架构：**
```text
quote_collector.py   腾讯 qt.gtimg.cn 批量行情（全市场分 10~20 批，3s/30s 节奏）
limit_detect.py      涨停检测纯函数（腾讯涨停价字段优先 + 板块/ST 阈值规则推导兜底）
intraday_collector.py 采集编排 + snapshots.ndjson 只增快照 + meta.json
realtime_engine.py   事件驱动：昨日定格指标(盘后) + 腾讯实时代入 → events + pool 实时维护
```
**技术栈：** Python 3.10 纯 stdlib（urllib）、pytest、腾讯行情 qt.gtimg.cn（已验证可达，88 字段含涨停价/跌停价/量比）。
