# 题材模型中文名与实时直播分组计划

## 目标

题材涨停卡片展示具体模型中文名；右侧实时直播将模型命中按分钟倒序分组，并展示股票中文名、代码、实时涨幅和命中模型。

## 任务 1：模型展示主数据（TDD）

1. 为 `config/strategy.json` 的 17 个模型补齐唯一中文 `name`，继续以配置作为模型展示名的唯一来源。
2. 增加测试，确保所有启用模型都有中文名，避免前端硬编码另一套映射。
3. 实时接口为每条模型命中输出 `model_names`，同时保留原 `model_hit` ID 供计算和追溯。

## 任务 2：实时行情字段（TDD）

1. 在接口测试中先要求模型命中包含 KPL 主数据中文股票名、腾讯快照的 `change_pct` 和首次命中时间。
2. 从最新腾讯快照只抽取命中股票的涨幅，不恢复下发 5000 只全市场行情。
3. 模型命中按时间倒序输出，缺少行情时显示空值而不伪造涨幅。

## 任务 3：题材 UI 与验收

1. 下方涨停卡片使用 `model_names` 展示中文模型名。
2. 右侧直播按分钟分组，每行展示中文名、代码、涨幅、模型中文名和评分；从普通事件区排除重复的 `signal_hit`。
3. 增加布局标记测试、运行全量测试，重启 API、部署静态页面并在今日实时模式进行浏览器验收。
